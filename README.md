# Spotted Sessions

One page estática para `spottedsessions.com`.

## Estructura

- `index.html`: contenido principal del sitio.
- `styles.css`: estilos responsivos en blanco, verde y negro.
- `assets/`: logos proporcionados para la marca.

El logo visible se renderiza como máscara CSS para evitar recuadros o cortes de
los archivos originales.

## Uso local

Abre `index.html` directamente en el navegador. No requiere instalación,
framework, build ni servidor local.

## Publicación

Para GitHub Pages, publica estos archivos desde la raíz de `main`.
`CNAME` mantiene conectado `spottedsessions.com` y `.nojekyll` evita que GitHub
procese assets como sitio Jekyll.
